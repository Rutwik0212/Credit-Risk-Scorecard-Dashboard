# Credit-Risk-Scorecard-Dashboard
Credit Risk Analysis Project

Project Overview

This project focuses on analysing loan applicant data to understand credit risk patterns and loan approval decisions. It uses a dataset of 1,000 synthetic loan applicant records to explore borrower profiles, financial information, risk classifications and lending outcomes.

The objective is to demonstrate practical knowledge of credit risk concepts, data organisation and financial analysis using Microsoft Excel.

Project Objectives

* Analyse borrower financial profiles and creditworthiness.
* Understand the relationship between credit scores and risk classifications.
* Examine loan amounts, monthly income and existing liabilities.
* Identify patterns in loan approval, rejection and review decisions.
* Analyse risk distribution across different employment categories and loan purposes.

Dataset Description

The dataset contains 1,000 synthetic loan applicant records with the following attributes:

Column	Description
Applicant ID- Unique applicant identifier
Age- Applicant’s age
Employment- Employment category
Monthly Income- Monthly income
Credit Score- Applicant’s credit score
Loan Amount- Requested loan amount
EMI- Monthly instalment
Existing Loans- Number of existing loans
Past Default- Previous default indicator
Loan Purpose- Purpose of the loan
Risk Level- Low, Medium or High
Approved- Approve, Reject or Review decision

Tools & Technologies

* Microsoft Excel: Data organisation, analysis and Pivot Tables.
* Synthetic Dataset: 1,000 simulated loan applicant records.

Analysis Performed

The Excel workbook contains three pivot analysis sheets:

1. Risk Distribution Analysis

* Low Risk: 276 applicants
* Medium Risk: 564 applicants
* High Risk: 160 applicants

2. Loan Purpose Analysis

Examined applicant distribution across five loan categories:

* Business
* Education
* Home
* Personal
* Vehicle

3. Employment-wise Approval Analysis

Analysed approval outcomes across:

* Salaried
* Self-employed
* Business
* Student

Overall decisions:

* Approved: 190
* Rejected: 403
* Review: 407

Key Observations

* Medium-risk applicants represent the largest risk category in the dataset.
* Personal loans have the highest applicant count among the five loan purposes.
* Salaried applicants represent the largest employment category.
* The dataset contains a mix of approved, rejected and review decisions.


The analysis is intended to demonstrate foundational credit risk assessment and data analysis concepts.
